# MVP Scope

## Must ship
- Username/password login
- Remember-me session persistence
- Signup with unique username + password
- At least one recovery contact: email or phone
- Password recovery by email reset or phone OTP
- Generic auth errors and rate limiting
- Display name / username
- Create private group
- Join via code/link
- Admin approval/rejection
- Owner/Admin/Member roles
- Current round with 16 fixtures
- Historical round navigation
- Per-round maximum doubles
- Draft autosave
- Submit/edit until lock
- Group submission view
- Democratic consensus generation
- Consensus versioning and vote breakdown
- Kickoff times and live score/status/minute
- Final score and Toto settlement outcome
- Automatic hit/miss evaluation
- Weekly and all-time statistics
- Per-fixture Kapiloto analysis
- Kapiloto caching, sources and freshness
- Admin whole-ticket Kapiloto review
- Diego full-ticket draft generation

## Brand / marketing track
- Original 3D Kapiloto and Diego character assets
- Authentication/onboarding character hero
- Optional contextual appearances in AI/loading/success states

## Shortly after MVP
- Push/email reminders
- Kapiloto recommendation-change timeline
- Advanced charts
- Admin audit-log UI
- More group visibility policies

## Explicitly excluded
No betting transactions or payment handling.
